================================================================================
  AZURE DISCOVERY TOOL - OFFLINE DEPLOYMENT GUIDE
================================================================================

This guide explains how to prepare and deploy the tool on systems without
internet access or where you want all dependencies pre-packaged.

================================================================================
  PREPARATION (On System with Internet)
================================================================================

STEP 1: Download All Python Packages
-------------------------------------

Run this command to download all required packages:

  download_packages_offline.cmd

This will:
- Download all packages from requirements.txt
- Save them to: offline_packages\
- Download pip, setuptools, and wheel
- Total size: ~200-300 MB

STEP 2: Verify Downloaded Packages
-----------------------------------

Check that packages were downloaded:

  dir offline_packages

You should see many .whl (wheel) files.

STEP 3: Optional - Download Azure CLI Installer
------------------------------------------------

If the target system doesn't have Azure CLI:

1. Download Azure CLI MSI installer from:
   https://aka.ms/installazurecliwindows

2. Save to: installers\AzureCLI.msi

================================================================================
  PACKAGING (Create Portable Package)
================================================================================

OPTION A: Copy Entire Folder
-----------------------------

Simply copy this entire folder to USB/network drive:

  Discovery\
  ├── tool\                     (Bundled Python 3.11)
  ├── offline_packages\         (All Python packages)
  ├── azure_discovery.py        (Main script)
  ├── config.json               (Configuration)
  ├── requirements.txt          (Package list)
  ├── run.cmd                   (Main launcher)
  ├── setup_offline.cmd         (Offline installer)
  └── ... (other files)

Folder size: ~400-500 MB total

OPTION B: Create ZIP Archive
-----------------------------

1. Compress the folder:
   - Right-click folder -> Send to -> Compressed folder
   OR
   - Use: Compress-Archive -Path . -DestinationPath AzureDiscovery.zip

2. Transfer the ZIP file to target system

3. Extract and run setup

================================================================================
  DEPLOYMENT (On Offline/New System)
================================================================================

OPTION 1: Automated Setup
--------------------------

1. Copy/Extract the folder to target system

2. Run offline setup:

   setup_offline.cmd

   This will:
   - Detect bundled or system Python
   - Install all packages from offline_packages\
   - Verify installation
   - Show next steps

3. Install Azure CLI (if needed):
   - Run installers\AzureCLI.msi
   OR
   - On a system with internet, download and install

4. Login to Azure:

   az login

5. Run discovery:

   run.cmd

OPTION 2: Manual Setup
-----------------------

If setup_offline.cmd fails, install manually:

1. Using Bundled Python:

   .\tool\python\python.exe -m pip install --no-index --find-links=offline_packages -r requirements.txt

2. Using System Python:

   python -m pip install --no-index --find-links=offline_packages -r requirements.txt

3. Verify installation:

   .\tool\python\python.exe verify_python.py

4. Run discovery:

   run.cmd

================================================================================
  VERIFICATION
================================================================================

Check Installation is Complete
-------------------------------

1. Verify Python:

   .\tool\python\python.exe --version
   
   Expected: Python 3.11.x

2. Verify packages:

   .\tool\python\python.exe verify_python.py
   
   Expected: All checks PASSED

3. Verify Azure CLI:

   az --version
   
   Expected: azure-cli version shown

4. Test Azure login:

   az login
   
   Expected: Browser opens for authentication

================================================================================
  TROUBLESHOOTING
================================================================================

Q: "offline_packages directory not found"
A: You need to run download_packages_offline.cmd on a system with internet first

Q: "No module named socket"
A: Use run_system_python.cmd instead, or install system Python

Q: "Package installation failed"
A: Try manual installation:
   .\tool\python\python.exe -m pip install --no-index --find-links=offline_packages -r requirements.txt -v

Q: Azure CLI not found
A: Download installer from: https://aka.ms/installazurecliwindows
   Or install on a system with internet access

Q: Tool works but some features fail
A: Check config.json - ensure all settings are correct
   Run: .\tool\python\python.exe verify_python.py

================================================================================
  UPDATING PACKAGES (Future Updates)
================================================================================

To update packages for newer versions:

1. Edit requirements.txt with new package versions

2. Re-run on internet-connected system:

   download_packages_offline.cmd

3. Copy new offline_packages\ folder to target systems

4. Re-run setup:

   setup_offline.cmd

================================================================================
  SYSTEM REQUIREMENTS
================================================================================

Minimum Requirements:
- Windows 10/11 or Windows Server 2016+
- 2 GB free disk space
- 4 GB RAM minimum
- Azure subscription with Reader access

Included Components:
- Python 3.11.8 (bundled)
- All Azure SDK packages (pre-downloadable)
- Git support libraries
- Excel generation libraries

Not Included (Must Install Separately):
- Azure CLI (download installer)
- Git (optional, for code scanning)
