================================================================================
  AZURE DISCOVERY TOOL - HOW TO RUN
================================================================================

🚀 QUICK START (3 STEPS):

1. LOGIN TO AZURE:
   Open PowerShell or Command Prompt and run:
   
   az login

2. RUN THE TOOL:
   
   ⭐ RECOMMENDED: Double-click this file in File Explorer:
   
      run.cmd
   
   OR from PowerShell/Command Prompt, run:
   
      run.cmd
   
   OR:
   
      .\run.cmd

3. WAIT FOR COMPLETION:
   The tool will scan your Azure environment (5-15 minutes)
   Reports will be saved in: discovery_output\

================================================================================

❓ TROUBLESHOOTING:

Q: I get "execution policy" or "not digitally signed" error
A: Use run.cmd instead of run_discovery.ps1
   The .cmd file bypasses PowerShell execution policy restrictions

Q: Python not found
A: The bundled Python is in tool\python\ folder
   The script will find it automatically

Q: Azure CLI not found
A: Install from: https://aka.ms/installazurecliwindows
   Then run: az login
